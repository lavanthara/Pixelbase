Pixelbase

Turn any image into a Base64 data URL. Fast, simple, and private.

Supports common browser image formats, including PNG, JPEG, WebP, GIF, SVG, and AVIF where supported.

The image host must allow cross-origin requests (CORS). If it blocks browser access, download the image and use the upload tab instead.

Converted image

Data URL can be used directly in HTML and CSS.

●
Private by design. Uploaded files are read locally in your browser. URL conversion fetches the image directly from its host; this page does not send images to its own server.
